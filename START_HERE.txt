iMAGE ? START HERE (Windows + VS Code)
=====================================

1. Open this project folder in VS Code and install Python/Jupyter extensions.
2. From a PowerShell terminal in the project root, run:

   py -3.11 -m venv .venv
   .\.venv\Scripts\python.exe -m pip install --upgrade pip
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   .\.venv\Scripts\python.exe -m pytest -q

3. Start the preview website:

   .\.venv\Scripts\python.exe -m uvicorn app.main:app --reload

   Visit http://127.0.0.1:8000. Preview filters are not neural models.

4. Obtain aligned SIDD and PolyU paired data. Read README.md, then run
   notebooks/01_prepare_5000_images.ipynb with the .venv kernel. Set the
   GT/LQ directory paths to your extracted data and keep the split manifest.
5. Run notebooks/02_finetune_models.ipynb for each model, starting with smoke
   mode. Complete full training before using the test set.
6. Run notebooks/03_evaluate_and_deploy.ipynb, starting with smoke mode.
   Review full 500-pair center-crop results before enabling deployment.
7. For real inference, stop the preview server and restart with:

   $env:IMAGE_MODE="real"
   .\.venv\Scripts\python.exe -m uvicorn app.main:app --reload

   The first real request downloads model sources and pretrained weights.
